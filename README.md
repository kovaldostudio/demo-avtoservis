# Конвеєр клієнтських сайтів — Kovaldo Studio

Шаблон, з якого збирається сайт для нового клієнта за 2–3 години.
Astro 7 (статика, нуль JS у рантаймі) + Tailwind 4 + Cloudflare Pages + Worker для заявок у Telegram.

---

## Новий сайт за сім кроків

```bash
# 1. Копія шаблону під клієнта
powershell -File ..\new-site.ps1 -Name stolyarka-lviv

# 2. Заповнити ОДИН файл
#    src/data/site.config.yaml

# 3. Подивитись, що вийшло
npm run dev

# 4. Перевірити перед показом (обовʼязково)
npm run qa

# 5. Підняти приймач заявок (один раз на клієнта)
cd worker
npx wrangler secret put TELEGRAM_TOKEN
npx wrangler secret put TELEGRAM_CHAT_ID
npx wrangler deploy
#    → отримаєш URL, вставити його у form.endpoint

# 6. Публікація
npm run deploy

# 7. Віддати клієнту посилання
```

## Що править кожен файл

| Файл | Роль |
|---|---|
| `src/data/site.config.yaml` | **Єдиний файл під клієнта.** Назва, контакти, каталог, ціни, відгуки, FAQ, тема |
| `src/styles/global.css` | Чотири теми оформлення. Нову тему додавати сюди |
| `src/components/sections/` | Секції сторінки. Спільні для всіх тем |
| `worker/` | Приймач заявок → Telegram. Один Worker на клієнта |
| `qa/checks.spec.ts` | Перевірки перед показом |

## Теми та варіанти

У `site.config.yaml`:

```yaml
theme: oak          # oak | graphite | linen | ink
heroVariant: split  # split | fullbleed | editorial
catalogVariant: grid # grid | list
```

| Тема | Характер | Шрифти |
|---|---|---|
| `oak` | тепле дерево, спокійна майстерня | Literata + Manrope |
| `graphite` | темний індустріальний цех | Oswald + IBM Plex Sans |
| `linen` | світлий мінімалізм, багато повітря | Playfair Display + Commissioner |
| `ink` | контрастна сучасна, для сміливих | Unbounded + Manrope |

12 комбінацій теми й героя. Два сусідні клієнти не отримають однакову сторінку —
це і є технічна відповідь на «щоб не було видно, що робив ШІ».

## Режим заглушок

```yaml
usePlaceholders: true
```

Замість фото малюються акуратні рамки «Тут буде ваше фото» з підказкою, що саме має стояти.
Для чого: вітрина в Instagram і демо не використовують чужих знімків — жодних питань
про авторські права. Для бойового сайту клієнта перемкнути на `false` і покласти фото в `public/img/`.

## Перевірка перед показом

```bash
npm run qa
```

Що робить:

- **Lighthouse** — швидкість, SEO, доступність. Пороги: performance ≥ 90, a11y ≥ 90, SEO ≥ 95. Нижче — падає.
- **Горизонтальний скрол** на 375 / 768 / 1440 px. Найчастіший дефект мобільної версії.
- **Мертві посилання** — `href="#"` і порожні.
- **Текст-заглушка** — Lorem ipsum, TODO, example.com.
- **Доступність** — axe-core, правила WCAG 2 A/AA.
- **Скріншоти** трьох розмірів у `qa/shots/`.

Плюс на кожній збірці аудит конфігу: якщо в ньому лишились поля з прикладу
(«Верстак», «example», демо-телефон) — попередження в консоль.

Поки `npm run qa` не зелений — клієнт сайту не бачить.

## Безпека форми

Два шари, обидва безкоштовні:

1. **Honeypot** — приховане поле `company`. Бот заповнює, людина ні. Worker відповідає 200, щоб бот не зрозумів, що його впіймали.
2. **Turnstile** — вписати `turnstileSiteKey` у конфіг і поставити `TURNSTILE_SECRET` у Worker. Без ключа працює лише honeypot.

`ALLOWED_ORIGIN` у `worker/wrangler.toml` обмежує, з якого домену приймаються заявки.
Лишити `*` означає дозволити будь-кому слати повідомлення у Telegram клієнта.
